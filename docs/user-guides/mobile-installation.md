# 📱 Mobile Installation & PWA Setup Guide

This guide explains how to install the BaitulMal Portal on your mobile device as a native-like application.

---

## 🛠️ Resolving "Package Parsing Error"

If you encounter the error **"There was a problem while parsing the package"** when installing the APK, it is likely due to one of the following:

1.  **Placeholder File**: The `app-release.apk` currently in the repository is a 1KB placeholder. A real native build requires a full Android build process (Android Studio/Gradle).
2.  **Incomplete Download**: Ensure the file was downloaded fully (check file size).
3.  **Android Version**: Native APKs are version-specific.

### 💡 The Recommended Solution: PWA (Progressive Web App)
Instead of a manual APK installation, we recommend using the **PWA (Add to Home Screen)** method. This provides:
- Instant updates (no need to reinstall).
- Native app icon on your home screen.
- Full-screen experience without browser bars.
- Secure, HTTPS-based delivery.

---

## 📲 How to "Set App on Home" (PWA Installation)

### **For Android (Chrome / Edge)**
1.  Open your mobile browser (Chrome is recommended).
2.  Navigate to the portal URL (e.g., `https://your-portal-url.com`).
3.  Tap the **Three Dots (⋮)** menu in the top-right corner.
4.  Select **"Install app"** or **"Add to Home screen"**.
5.  Confirm the installation. The BaitulMal icon will now appear on your home screen.

### **For iOS (Safari)**
1.  Open **Safari** on your iPhone.
2.  Navigate to the portal URL.
3.  Tap the **Share Icon** (square with an arrow pointing up) at the bottom.
4.  Scroll down and tap **"Add to Home Screen"**.
5.  Tap **"Add"** in the top-right corner.

## 🔋 Fail-Safe Verification

If the "Install" option does not appear in your browser, verify the following:
1.  **HTTPS**: The site must be served over a secure connection (`https://`).
2.  **Manifest Integrity**: Ensure `public/manifest.json` is present.
3.  **Service Worker**: Ensure `public/sw.js` is registered (check DevTools > Application > Service Workers).
